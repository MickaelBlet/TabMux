# Changelog

All notable changes to this project are documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [0.1.0] - 2026-11-23

### Added

- Terminal multiplexer with tabs in a sidebar (with a pane tree) or a top bar.
- Nested split panes: resize, zoom, drag-and-drop between tabs.
- Full mouse support: buttons with tooltips, selection, copy via OSC 52,
  middle-click paste, forwarding to programs that request mouse events.
- tmux-style `^b` prefix keybindings and a help screen (`^b ?`).
- Scrollback search (smart case) and prompt navigation (`Ctrl+↑/↓`) with
  automatic zsh / bash shell integration (OSC 133).
- Wide mode (1000-column PTY with horizontal scrolling) and multicursor typing.
- Bell and activity markers on background tabs.
- TOML workspace files: tabs, layouts, commands, env, shell profiles.
- `--nerd-font` option (or `TABMUX_NERD_FONT=1`) to draw `[x]` buttons as
  rounded pills.
- Separator segments bordering the focused pane, and its scrollbars, are
  drawn in a focus color.
- Separators, sidebar border and `[▤]` button are drawn purple in
  multicursor mode.
- Documentation in `docs/` with SVG UI captures generated by
  `scripts/screenshots.sh`.
- GitHub Actions workflow building x86_64 / aarch64 Linux binaries
  compatible with glibc 2.28, published as release assets on `v*` tags.
